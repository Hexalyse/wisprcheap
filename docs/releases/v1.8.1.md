# WisprCheap 1.8.1

- **Sync clock-skew recovery.** Use the server's clock (`server_time`) to avoid persisting a poisoned future HLC, recover already-skewed local sync state once the system clock is fixed, and retry `clock_skew`-rejected history entries without advancing the history offset past them.
- **Sync privacy and state locking.** Strip local `audioFile` paths from synced history on both upload and download, write sync state and downloaded history with private Unix permissions (`0600`), and serialize sync CLI config edits under `EDIT_LOCK` and `StateLock`.
- **Reliable paste & selection capture.** Propagate Windows, X11, and Linux `uinput` key-injection errors (releasing pressed modifiers on X11 failure), retry transient Windows clipboard lock contention, leave transcripts on the clipboard when paste fails, and abort command/add-word selection capture if copy fails so unrelated clipboard text is never sent.
- **Optional log redaction.** Added `history.log_dictated_text` (default `true`) so dictated text and commands can be kept out of logs when desired.

Configuration, history and sync formats remain compatible.
