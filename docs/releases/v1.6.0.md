# WisprCheap 1.6.0

- Replace the Linux GTK3 desktop integration with GTK4 and a GTK-free KSNI tray.
- Replace Tao with Winit on Windows; keep the existing Iced settings/history companion.
- Preserve overlay animation, click-through, focus, scaling, live tray menus and session-log behavior.
- Remove the vulnerable legacy GLib dependency and its temporary backport. Update affected Rust
  TLS/cryptography dependencies and add automated dependency checks.
- Prevent redirects forwarding API keys, audio/text payloads and sync pairing codes.
- Bound sync response sizes and untrusted Argon2 parameters; restrict sensitive Unix files to their owner.
- Harden sync-server password work, throttling and forwarded-address handling (released as server 0.2.1).

**Linux compatibility:** release binaries now require Ubuntu 24.04 / glibc 2.39 or newer and system GTK4.
Keep the bundled `lib/` directory next to the executables; it contains GTK4 Layer Shell and its license.
Source builds require Rust 1.92+. Configuration, history and sync wire formats remain compatible.

See [GTK4 migration](https://github.com/Hexalyse/wisprcheap/blob/v1.6.0/docs/gtk4-migration.md) and the
[security review](https://github.com/Hexalyse/wisprcheap/blob/v1.6.0/docs/security-review-2026-10-31.md)
for validation, deployment caveats and remaining risks.
