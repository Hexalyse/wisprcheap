# WisprCheap 1.8.0

- **Edge glow overlay on Windows.** `overlay.style: edgeGlow` now works on Windows too: a soft blue glow along the
  bottom of the focused window and up its sides, with the same colors and motion as on Linux. It follows the window
  when it moves or the focus changes while you speak, follows Windows 11's rounded corners, and uses the bottom of the
  screen (above the taskbar) when the desktop or the taskbar has the focus. It's drawn at the monitor's resolution, only
  along the edges it lights.
- **Dropdowns in the settings window.** **Overlay style** and the speech-to-text **Provider** are picked from a list
  instead of typed. A `${VAR}` reference in the config file stays editable as text.

Configuration, history and sync formats remain compatible.
