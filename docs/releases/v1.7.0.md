# WisprCheap 1.7.0

- **Omarchy dictation backend.** `wisprcheap record <start|stop|toggle|cancel>` drives a dictation from outside, so
  Omarchy's dictation keys (Alt + Space, hold Right Alt) can use wisprcheap. `contrib/omarchy/install.sh` adds
  **WisprCheap** to Omarchy's menu next to Voxtype and Superwhisper (Setup > Defaults > Dictation); picking it sets up
  the keyboard access, starts wisprcheap at login and selects it. `hotkey.keys: []` turns off wisprcheap's own
  dictation shortcut.
- **Edge glow overlay (Linux).** `overlay.style: edgeGlow` replaces the pill with a soft blue glow along the bottom of
  the active window and up its sides, like Superwhisper's. Its wave drifts slowly in silence, speeds up and rises as
  you speak, and settles back in pauses. It follows the focused window on Hyprland; elsewhere it uses the bottom of the
  screen.
- **Pasting into terminals.** On Linux, terminals get Ctrl+Shift+V (and Ctrl+Shift+C for command mode) instead of
  Ctrl+V, which typed a literal ^V. Common terminals and the windows Omarchy tags `terminal` are recognized on Hyprland
  and X11; `output.terminalApps` adds others.
- **Voice level relative to the room's noise.** The waveform bars and the glow measure the voice above the background
  noise and ignore DC offset, so a loud or boosted microphone no longer shows full bars in silence.
- The settings window and files opened from the tray no longer leave zombie processes behind while wisprcheap runs.

**Linux compatibility:** GTK 4.14 or newer is now required (Ubuntu 24.04 ships 4.14). Configuration, history and sync
formats remain compatible.
